# Resource pack

Pon aqui TUS PROPIAS texturas, sonidos y fuentes (no copies assets de Eufonia ni de otros mods).

- `pack_format` depende de la version de Minecraft. Comprueba el valor correcto en
  https://minecraft.wiki/w/Pack_format y ajusta `pack.mcmeta`.
- Ideas: sonido de ruleta, sonido de muerte, iconos de fuente para instrucciones,
  modelos de items con `custom_model_data`.
